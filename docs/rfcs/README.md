# OpenCrust RFCs

This directory contains Request for Comments (RFC) documents for major changes to OpenCrust.

## RFC Process

1. **Create RFC**: Copy `0000-template.md` to a new file named `NNNN-short-title.md` (next available number)
2. **Fill in template**: Complete all sections with your proposal
3. **Open Discussion**: Create a GitHub Discussion with the RFC content
4. **Review Period**: Minimum 7 days for community feedback
5. **Decision**: Maintainers approve, request changes, or reject
6. **Implementation**: If approved, implement per the plan
7. **Finalize**: Update RFC status to "Accepted" or "Rejected"

## Status Values

- **Draft** - Work in progress, not ready for review
- **Proposed** - Ready for community review
- **Accepted** - Approved for implementation
- **Rejected** - Not accepted, with rationale
- **Implemented** - Merged and released
- **Deferred** - Postponed, may be revisited

## Naming Convention

`NNNN-short-descriptive-title.md`

Examples:
- `0001-provider-trait-architecture.md`
- `0002-plugin-system-design.md`
- `0003-async-tool-execution.md`
